Teal's Daily Fact Challenge v2.24.0 — INTERACTIVE MATH UPDATE ONLY

Use this package when the currently deployed app is the working v2.23.0 release.

New:
- Compare Values: students choose <, =, or >.
- Order Tiles: students drag 3–6 number tiles least→greatest or greatest→least.
- Both types work in Igniter, Quiz of the Week, Indiana Question Bank, and Monday Recovery.
- Exact decimal/fraction/mixed-number comparison and ordering.
- Mouse/touch drag plus keyboard arrow-key reordering.
- Eight existing permanent bank questions converted to interactive formats, including four Grade 5 5.NS.1 items.

Install:
1. Upload/replace everything inside UPLOAD_TO_GITHUB in the normal Daily Fact Challenge GitHub repository.
2. Commit with: v2.24.0 - add Compare Values and draggable Order Tiles questions
3. Wait for Streamlit to redeploy.
4. Test Compare Values and Order Tiles with Test Student.

No new Supabase SQL is required.
No Secrets changes are required.
