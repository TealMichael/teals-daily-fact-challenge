Teal's Daily Fact Challenge v2.20.1 — Browser GitHub Install Only

PURPOSE
Hotfix for a completed Daily 10 that fails to save and otherwise leaves the student stranded.

UPLOAD THESE 4 FILES TO THE ROOT OF YOUR GITHUB REPOSITORY:
- app.py
- fact_engine.py
- student_alt_daily_ui.py
- student_daily_save_recovery.py   (NEW FILE)

BROWSER-ONLY GITHUB STEPS
1. Open your teals-daily-fact-challenge repository on GitHub.com.
2. Confirm you are on the main branch.
3. Choose Add file -> Upload files.
4. Drag all four .py files from this folder into the repository root.
5. Confirm app.py, fact_engine.py, and student_alt_daily_ui.py show as replacements, and student_daily_save_recovery.py shows as a new file.
6. Commit directly to main.
7. Let Streamlit redeploy.
8. Confirm the app version displays v2.20.1.

NO OTHER INSTALL STEPS
- No Supabase SQL.
- No Streamlit Secret changes.
- No AWTRIX reinstall or clock changes.
- No browser component folders changed.

WHAT THE HOTFIX DOES
- Saves a completed Daily payload into temporary Streamlit session state before the first database save attempt.
- If saving fails, shows a visible "Try saving again" button.
- Retrying reuses the exact completed payload; the student does not redo the Daily 10.
- The existing browser localStorage remains a second recovery layer after a hard refresh.
- Applies to Multiplication and alternate Daily modes.

Suggested GitHub commit message:
v2.20.1 - prevent students getting stranded after Daily save failure
