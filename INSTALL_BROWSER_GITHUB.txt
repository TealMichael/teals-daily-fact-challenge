GITHUB BROWSER STEPS
1. Open your existing Teal's Daily Fact Challenge repository.
2. Choose Add file → Upload files.
3. Drag all 6 files above into the upload area.
4. GitHub should show replacements for the existing 4 files and additions for the 2 new files.
5. Commit with:
   v2.19.9 - add Perfect Score Club after Top 10
6. Wait for Streamlit Cloud to redeploy.

SUPABASE STEP — REQUIRED ONCE
1. Open RUN_THIS_ONCE_IN_SUPABASE_v2_19_9.sql from this package (or from GitHub after upload).
2. Copy the entire SQL file.
3. Open Supabase → SQL Editor → New query.
4. Paste it and click Run ONCE.

WHAT CHANGES
- Existing Top 10 stays exactly the same.
- After Top 10, 10/10 students who are not already Top 10 appear in Perfect Score Club.
- Perfect Score Club is alphabetical, not speed-ranked.
- The classroom clock appends Perfect Score Club after Top 10 automatically.
- If nobody qualifies outside Top 10, nothing extra is shown.
