Teal's Daily Fact Challenge v2.16.2 — Mystery Clue Reliability Hotfix
===================================================================

Install over the currently deployed v2.16.1 app.

1. Unzip the v2.16.2 GitHub Desktop patch.
2. Open COPY_INTO_GITHUB_REPO.
3. Copy everything inside that folder into the root of the existing GitHub repository.
4. Allow replacements.
5. Review the changes in GitHub Desktop, commit, and push.
6. Let Streamlit Cloud redeploy.

No Supabase SQL migration is required.
Do not rerun older SQL migrations.
No Streamlit Secret changes are required.
No AWTRIX reinstall or clock changes are required.

Student recovery after deployment
---------------------------------
If a student is missing a Mystery clue even though they completed that day's required routine, have the student reopen Today after the deployment. The app checks the current Mystery week and restores a missing prior-day clue only when saved completion records prove the student earned it. A day the student genuinely skipped remains locked.

What changed
------------
- Weekly Mystery reads/writes now use the same transient HTTP retry protection as other classroom-critical store operations.
- A lost clue-write response is re-read safely so a successful insert is not mistaken for failure.
- Prior-day clue receipts can be repaired from already-saved completion records.
- Today's clue is saved first so the optional prior-day repair cannot block the current reward.
- Mystery clue load failures now give students a simple retry action while confirming their finished work is saved.

Rollback
--------
The v2.16.1 full-current-app package remains the rollback source. This release adds no schema changes, so rollback is code-only.
