Teal's Daily Fact Challenge v2.16.4 — Alternate Daily Today Hotfix
=================================================================

Install over v2.16.3. The patch is also cumulative over v2.16.1/v2.16.2 because it carries the v2.16.3 touch-keypad and v2.16.2 Mystery-clue fixes.

1. Unzip the v2.16.4 GitHub Desktop patch.
2. Open COPY_INTO_GITHUB_REPO.
3. Copy everything inside that folder into the root of the existing GitHub repository.
4. Allow replacements.
5. Review the changes in GitHub Desktop, commit, and push.
6. Let Streamlit Cloud redeploy.

No Supabase SQL migration is required.
Do not rerun older SQL migrations.
No Streamlit Secret changes are required.
No AWTRIX reinstall or clock changes are required.

What changed
------------
- Teacher → Today now understands that alternate Daily modes end after question 10.
- Completed Addition, Subtraction, Division, Integers, and Mixed attempts count as Done.
- Alternate-mode students no longer appear under Follow-up practice remaining or as Fix Your Misses / Focus Practice.
- Multiplication keeps the existing Daily → Fix Misses → Focus → Done routine unchanged.
- Student-side Daily behavior is unchanged.

Rollback
--------
The v2.16.3 full-current-app package is the immediate rollback source. This release adds no schema changes, so rollback is code-only.
