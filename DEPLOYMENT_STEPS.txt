WHAT CHANGED
Teacher -> Classes & Students -> Roster Management now uses a true bulk database delete:
- Select one or many students and press Delete selected student(s).
- All selected accounts are deleted in one database request instead of one student at a time.
- Student-linked Daily, Practice, mastery, Focus, and Mystery rows are removed by existing database cascades.

A new fast cleanup tool is also available:
- Expand “Clear this entire roster (N students)” under Roster Management.
- Type DELETE followed by the exact class name.
- One action permanently clears every student currently in that class while keeping the class itself.

For the current duplicate-roster cleanup, this is the fastest option if every student in that wrong roster should be removed.
