Teal's Daily Fact Challenge v2.16.3 — Daily Touch Keypad Hotfix
================================================================

Install over v2.16.1 or v2.16.2. This patch is cumulative and includes the v2.16.2 Mystery clue reliability fix if it is not already installed.

1. Unzip the v2.16.3 GitHub Desktop patch.
2. Open COPY_INTO_GITHUB_REPO.
3. Copy everything inside that folder into the root of the existing GitHub repository.
4. Allow replacements.
5. Review the changes in GitHub Desktop, commit, and push.
6. Let Streamlit Cloud redeploy.

No Supabase SQL migration is required.
Do not rerun older SQL migrations.
No Streamlit Secret changes are required.
No AWTRIX reinstall or clock changes are required.

What changed
------------
- Daily 10 digit entry now updates only the answer display instead of rebuilding the entire keypad after each digit.
- The number buttons remain mounted between the first and second digit of an answer such as 10, 20, 30, and 100.
- Back navigation, answer editing, hidden timing, first-answer evidence, final scoring, and local Daily continuity remain unchanged.
- All other student and teacher components remain unchanged from v2.16.2.

Rollback
--------
The v2.16.2 full-current-app package is the immediate rollback source if you were already on v2.16.2. This release adds no schema changes, so rollback is code-only.
