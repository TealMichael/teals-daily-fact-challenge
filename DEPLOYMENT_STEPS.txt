TEAL'S DAILY FACT CHALLENGE v2.13.0 — WEEKLY DAILY 10 + IGNITER UPDATE

SOURCE OF TRUTH
This release is built from v2.12.0 Hotfix 3. Do not install it over a different experimental branch.

IMPORTANT ORDER
Run the v2.13 Supabase SQL FIRST. Then deploy the GitHub files.
The SQL migration is backward-compatible with the currently installed v2.12.0 Hotfix 3 app, so there is no period where the old app should be broken after the SQL runs.

STEP 1 — SUPABASE
1. Open your existing Teal's Daily Fact Challenge Supabase project.
2. Open SQL Editor.
3. Open `RUN_THIS_ONCE_IN_SUPABASE_v2_13.sql` from this package.
4. Paste the entire file into a new query and run it once.
5. Confirm the query completes successfully before touching GitHub.

The migration adds:
- `daily_mode` to existing Daily attempts, defaulting old/current records to Multiplication.
- `custom_questions` and `custom_answers` JSON fields for nonmultiplication Daily 10 attempts.
- the expanded allowed Igniter question-type constraint.

Do NOT rerun older migrations as part of this update.

STEP 2 — GITHUB DESKTOP / REPOSITORY
Use the PATCH ZIP for the normal update.

1. Unzip `Teals_Daily_Fact_Challenge_v2_13_0_GITHUB_DESKTOP_PATCH.zip`.
2. Open the folder `COPY_INTO_GITHUB_REPO` inside it.
3. Copy everything INSIDE that folder into the root of your existing GitHub repository.
4. Allow the files to replace/update the matching files already in the repository.
5. Open GitHub Desktop and review the changed files.
6. Commit with:
   v2.13.0 - add flexible Daily 10 modes and expanded Igniter answers
7. Push to GitHub.
8. Let Streamlit redeploy normally.

The FULL_CURRENT_APP ZIP is your complete v2.13 backup/reference package; it is not necessary to copy the entire archive for the normal GitHub Desktop update.

STEP 3 — QUICK TEACHER CHECK AFTER DEPLOY
1. Sign in as Teacher.
2. Open Daily 10 Setup.
3. Confirm all classes show Multiplication by default.
4. Pick one future/today class and temporarily choose a nonmultiplication mode if you want a live check.
5. Confirm the setting saves for only that class/date.
6. Open Warm-Up/Igniter and confirm the planner defaults to today and the new answer types appear.

STEP 4 — WHAT NOT TO CHANGE
- Do not reinstall or edit the AWTRIX Fact Top 10 script for v2.13.0.
- Do not change the separate classroom Class Schedule script.
- Do not add/change Streamlit Secrets.
- Do not change the multiplication Daily generator or challenge version.

ROLLBACK
If you need to roll the code back, redeploy the known-good v2.12.0 Hotfix 3 GitHub files. The added v2.13 database columns are backward-compatible and may remain in Supabase; you do not need to drop them to run Hotfix 3 again.
