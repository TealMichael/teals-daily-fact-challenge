2. Copy everything from the v2.19.1 GitHub Desktop patch's COPY_INTO_GITHUB_REPO folder into the root of your existing GitHub repository.
3. Allow replacements.
4. In GitHub Desktop, review the changes, commit, and push.
5. Let Streamlit Cloud redeploy.
6. Test one alternate Daily through the transition into Focus Practice.
