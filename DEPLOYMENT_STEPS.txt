Teal's Daily Fact Challenge v2.14.0 — Teacher Command Center

INSTALL
1. No Supabase SQL is required.
2. Copy the v2.14.0 GitHub Desktop patch into the root of the existing v2.13.2 repository.
3. Allow replacements.
4. Commit and push in GitHub Desktop.
5. Let Streamlit Cloud redeploy, then reload the app.

WHAT THIS RELEASE ADDS — TEACHER SIDE ONLY
- Teacher → Today becomes a command center with an All Classes Snapshot.
- The selected class shows a focused “What needs you” action list instead of making the teacher hunt through data.
- Teacher-only attendance exceptions can mark not-started students absent for that class/date. This changes teacher completion denominators only; it does not alter student accounts, attempts, history, or mastery.
- Teacher navigation is grouped into Today | Warm-Up | Learning | Manage, while retaining all existing teacher tools.
- Daily 10 Setup remains available inside Classes & Rosters.
- Student Support has an explicit confirmed “Reopen with a fresh Daily attempt” action using the existing reset/rebuild behavior.
- Student Support uses clearer Archive student / Restore student wording while preserving the existing inactive-student behavior and history.
- Today shows an Indiana-time freshness stamp and isolates transient teacher-data failures so one failed read does not unnecessarily take down the whole dashboard.

WHAT IT DOES NOT CHANGE
- No Supabase migration or schema change.
- No new Streamlit Secret.
- No student-facing design or workflow changes.
- No Daily 10 scoring/generation changes.
- No multiplication/mastery algorithm changes.
- `TDFC-DAILY-v1` remains unchanged.
- No Warm-Up student behavior changes.
- No Weekly Mystery student behavior changes.
- No AWTRIX script or clock changes.
- No login/PIN behavior changes.

ROLLBACK
Re-deploy the prior v2.13.2 repository commit. No database rollback is needed because v2.14.0 has no database migration.
