Teal's Daily Fact Challenge v2.21.2 — Temporary Question Images

IMPORTANT
- v2.21.1 FULL CURRENT APP is the source this release was built from.
- This release adds optional images only to Igniter and Quiz of the Week questions.
- Daily 10, Fix Your Misses, Focus, teaching models, Mystery, Top 10, Perfect Score Club, AWTRIX, login/session, and Skyward privacy architecture are intentionally unchanged.

INSTALL
1. In the existing Daily Fact Challenge Supabase project, open SQL Editor.
2. Run RUN_THIS_ONCE_IN_SUPABASE_v2_21_2.sql exactly once.
   This creates a PRIVATE question-images Storage bucket and a tiny private metadata table used only for image expiration.
3. Upload/replace the v2.21.2 files from this package to the repository root, preserving folders.
4. Commit with:
   v2.21.2 - add temporary question images for Igniter and Quiz of the Week
5. Let Streamlit redeploy. No Secrets changes are required.
6. Confirm the app footer shows v2.21.2.

TEACHER USE
- In either Igniter or Quiz of the Week, each question now has an optional PNG/JPG/WEBP uploader.
- Uploads are resized/compressed before storage.
- Saved images are private and served to students with short-lived signed URLs.
- Image files are automatically eligible for deletion 7 days after the scheduled question date.
- Cleanup runs from teacher curriculum pages and never blocks classroom use if cleanup temporarily fails.
- Old question text, answer keys, scores, and history remain intact after the image itself expires.
